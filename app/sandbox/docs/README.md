# Sandbox ドキュメント

このディレクトリは sandbox アプリケーション固有の設計と仕様を管理します。プロジェクト全体に適用する方針は [`../../../docs/development.md`](../../../docs/development.md) を参照してください。

## 読み順

1. [`design.md`](design.md) — 現在の設計、責務の境界、依存、実装段階を確認します。
2. [`roadmap.md`](roadmap.md) — 未着手・進行中の作業を確認します。
3. [`decisions/`](decisions/) — 重要な設計判断の背景を確認します（記録がある場合）。

現在、Vulkan の画面クリアと Dear ImGui による sandbox 状態表示まで実装済みです。シェーダー描画、操作 UI、物理シミュレーションの残作業は `roadmap.md` を参照してください。

## 更新ルール

- `design.md` を現在有効な設計・仕様の正本とし、合意・実装に合わせて更新します。
- 未決定または未実装の提案は、その状態を本文で明示します。
- 作業項目が増えたら `roadmap.md` に記録し、完了した項目は取り除きます。
- 後から理由を参照する価値がある重要な判断は `decisions/` に記録します。日々の実装詳細や、設計書に書けば十分な内容は記録しません。
- 同じ仕様を複数の文書に複製せず、必要なら正本へのリンクを置きます。
- 設計変更時は、この索引、設計の正本、関連する作業項目と決定記録を確認し、古い説明を現行仕様として残さないようにします。
